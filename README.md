# FoxyCraft Launcher Mods

Mods and shaders source for the FoxyCraft Launcher Rust Edition.

The launcher reads `index.json` from this repository to list downloadable
mods and shader packs. Files live under `files/` and are verified by the
launcher against the SHA-256 checksums recorded in the index before install.

All mods and shaders belong to their original authors; see each entry in
`index.json` for author and license details.
